# Копилка — APK через GitHub Actions
1. Создайте репозиторий на GitHub и загрузите в него все файлы этой папки (включая скрытую папку .github).
2. Откройте вкладку Actions → Build APK → Run workflow (или просто сделайте push в main).
3. Через 3–5 минут скачайте app-debug.apk из раздела Artifacts (kopilka-apk).
